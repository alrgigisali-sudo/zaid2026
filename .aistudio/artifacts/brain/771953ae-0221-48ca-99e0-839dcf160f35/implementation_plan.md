# خطة العمل: إضافة بطاقات اشتراك الفصل الدراسي وتحديث إدارة التراخيص

## 1. التغيرات والميزات المحددة
- **عرض بطاقتين منفصلتين في جميع نوافذ الاشتراك (الصفحة الرئيسية + نافذة الاشتراك والتفعيل):**
  - **قسم المعلم:**
    - بطاقة اشتراك سنة كاملة (90 ريال).
    - بطاقة اشتراك فصل دراسي واحد (49 ريال).
  - **قسم المدرسة:**
    - بطاقة اشتراك سنة كاملة (129 ريال).
    - بطاقة اشتراك فصل دراسي واحد (59 ريال).

- **تحديث المحرك البرمجي للتراخيص (`licenseEngine.ts`):**
  - إضافة دعم نوع مدة الاشتراك (سنوي / فصل دراسي واحد).
  - ضبط تاريخ انتهاء التراخيص:
    - سنوي: 1 سنة كاملة (365 يوم).
    - فصل دراسي: 120 يوم (أو الفصل الحالي).
  - تحديث قيمة التكلفة الافتراضية لكل ترخيص مدرسة (129 / 59) ومعلم (90 / 49).

- **تحديث لوحة تحكم المدير وتوليد التراخيص (`AdminLicenseManagerModal.tsx`):**
  - إضافة خيار اختيار نوع مدة الاشتراك (سنة كاملة / فصل دراسي واحد) عند توليد كود جديد للمدرسة أو المعلم.
  - حساب الإحصائيات والإيرادات بناءً على نوع الباقة الصادرة تلقائياً.
  - تحديث نص رسالة الواتساب المولدة للعميل لتوضيح نوع الاشتراك (سنة / فصل دراسي).

## 2. خريطة التعديلات الملفية
- `/src/utils/licenseEngine.ts`: إضافة خيار مدة الاشتراك وحساب أسعار وتواريخ انتهاء تراخيص الفصل الدراسي مقابل السنوية.
- `/src/components/admin/AdminLicenseManagerModal.tsx`: إضافة واجهة تحديد مدة الترخيص (سنوي/فصل دراسي) وإبراز الأسعار وإعادة إحصائيات الإيرادات.
- `/src/components/common/SubscriptionModal.tsx`: تصميم بطاقتين منفصلتين متجاورتين لكل باقة (سنوي / فصل دراسي) بإمكانية اختيار الشراء المباشر أو التفعيل.
- `/src/components/common/PlatformOverviewHome.tsx`: تحديث قسم الاشتراك في الصفحة الرئيسية ليعرض كروت الباقات السنوية والفصلية بشكل احترافي وواضح.

## 3. خطة التحقق والإنتاج
- تشخيص واختبار بناء التطبيق عبر `compile_applet` و `lint_applet`.
- التأكد من تجاوب البطاقات للطباعة والشاشات المختلفة وحساب التراخيص بدقة.
